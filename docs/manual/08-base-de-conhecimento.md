# 8. Base de conhecimento

[← Índice](README.md)

## Para que serve

Guardar as soluções que se repetem: o passo a passo que resolveu um problema, para quem atender da próxima vez. Os artigos também aparecem como sugestão quando alguém vai abrir um chamado parecido.

## Procurar uma solução

1. Abra **Base de conhecimento** no menu.
2. Descreva o problema na busca, do jeito que o cliente fala (ex.: "boleto não aparece").
3. Se quiser, filtre por **cliente** ou por **time**.
4. Clique no artigo para ler.

## Escrever um artigo

1. Clique em **Novo artigo**.
2. **Título**: o problema, como o cliente descreve (ex.: "Boleto não aparece no site do cliente").
3. **Cliente** (opcional): deixe **Vale para todos** se a solução serve para qualquer cliente.
4. **Time** (opcional).
5. **Etiquetas**, separadas por vírgula (ex.: "boleto, financeiro, remessa").
6. **Solução**. Um formato que funciona bem:

   ```
   Sintoma: ...
   Causa: ...
   Como resolver:
   1. ...
   2. ...
   ```

7. Salve.

**Atalho pelo chamado:** em um chamado resolvido, o botão **Salvar solução na base** abre um artigo novo já preenchido com o que resolveu.

## Editar e excluir

No artigo, use **Editar artigo** ou **Excluir artigo**.

## Base para o atendimento automático

Se o administrador ligou o agente de atendimento automático (veja [Administração](17-administracao.md#integrações)), ele só lê os artigos com a etiqueta escolhida na configuração. O resto da base continua interno.

## Quem pode

| Ação | Administrador | Membro | Somente leitura |
| --- | --- | --- | --- |
| Ler e buscar artigos | Sim | Sim | Sim |
| Escrever e editar artigos | Sim | Sim | Não |
| Excluir artigos | Qualquer um | Só os que escreveu | Não |
